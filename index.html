Featured Systems & Projects

Career Switch Prediction System

Scikit-Learn · Pandas · Stratified 5-Fold

An end-to-end classification system benchmarked on 5,000 real candidate profiles to predict tech career-switch intent. Formulated to combat extreme class imbalance (74.8% stay vs. 25.2% switch) through class-weighted loss penalties, comparing Logistic Regression, KNN, and an MLP Neural Network against an unsupervised K-Means baseline.

Benchmark F1: 0.519
ROC-AUC: 0.716
Switch Recall: 0.627
Validation: Stratified 5-Fold CV
